### Textual data

<Admonition type="note" title="">

`str` - A single text entry.  
`list[str]` - An array of text entries.

</Admonition>

---
    
### Numerical data

* You can store **pre-generated** embedding vectors in your documents,  
  typically created by machine-learning models from text, images, or other sources.

* When storing numerical embeddings in a document field:  
  * Ensure that all vectors within this field across all documents in the collection are generated by the **same model** and model version and have the **same dimensions**.
  * Consistency in both dimensionality and model source is crucial for meaningful comparisons in the vector space.

---
    
<Admonition type="note" title="">

**Raw embedding data**:  
Use when precision is critical.  

`list[float]` - A single vector of numerical values representing raw embedding data.  
`list[list[float]]` - An array of vectors, where each entry is a separate embedding vector.  

</Admonition>

<Admonition type="note" title="">

**Pre-quantized data**:   
Use when you prioritize storage efficiency and query speed.  

`list[int]` - A single pre-quantized embedding vector in the `Int8` or `Binary` format.  
`list[list[int]]` - An array of `Int8` or `Binary` embedding vectors.  

Prepare these vectors using RavenDB's vector quantizer methods ([VectorQuantizer reference](../../../ai-integration/vector-search/quantization.mdx#vectorquantizer-reference)):

* `VectorQuantizer.to_int8` returns a `list[int]` that includes the metadata required by RavenDB.
* `VectorQuantizer.to_int1` returns a `list[int]` with one bit per dimension packed into bytes.

</Admonition>

<Admonition type="note" title="">

**Base64-encoded data**:  
Use when embedding data needs to be represented as a compact and easily serializable string format.

`str` - A single vector encoded as a Base64 string.    
`list[str]` - An array of Base64-encoded vectors.    

The string must encode the vector's binary bytes in its source format (`Single`, `Int8`, or `Binary`).  
For example, encode a `list[float]` in `Single` format as follows:

```python
import base64
import struct

embedding = [0.1, 0.2, 0.3]
base64_embedding = base64.b64encode(
    struct.pack("f" * len(embedding), *embedding)
).decode("utf-8")
```
<br/>

To encode `Int8` data, use the `list[int]` returned by `VectorQuantizer.to_int8`,  
which includes the required metadata.

```python
from ravendb.documents.queries.vector import VectorQuantizer

quantized = VectorQuantizer.to_int8(embedding)
base64_int8_embedding = base64.b64encode(
    struct.pack("b" * len(quantized), *quantized)
).decode("utf-8")
```
<br/>

See a query example using `vector_search_with_base64` in
[Dynamic vector search - querying NUMERICAL content](../../../ai-integration/vector-search/vector-search-using-dynamic-query.mdx#dynamic-vector-search-querying-numerical-content).

For `Int8` or `Binary` data, use `vector_search_with_base64_i8` or `vector_search_with_base64_i1`  
(see the method table in [Syntax](../../../ai-integration/vector-search/vector-search-using-dynamic-query.mdx#syntax)).

</Admonition>
