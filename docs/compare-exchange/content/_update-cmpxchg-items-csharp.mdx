<Admonition type="note" title="">

* The _value_ or _metadata_ of an existing compare-exchange item can be updated.

* To update a compare-exchange item, provide:
  * The existing key
  * A new value or metadata
  * The latest index (version) of the item as known to the client.

* The update will succeed only if the index you provide is exactly the same as the current index stored on the server for the same key.
  This ensures that updates are applied only if no other changes were made to the item since it was last read by the client.

* If the indexes do not match, the operation fails and returns the current value and index from the server.  
  If the update is successful, the server increments the index and returns the new value and index.

    store.Operations.Send(

// Update the compare-exchange item
// The put operation will succeed only if the 'index' of the compare-exchange item

    = store.Operations.Send(
        new PutCompareExchangeValueOperation<User>("user1-name@example.com", readResult.Value, readResult.Index));

### Syntax

**Method**:

<TabItem value="put_0" label="put_0">
<CodeBlock language="csharp">
{`public PutCompareExchangeValueOperation(string key, T value, long index)
`}
</CodeBlock>
</TabItem>

| Parameter | Type     | Description                                                                                                                          |
|-----------|----------|--------------------------------------------------------------------------------------------------------------------------------------|
| **key**   | `string` | Object identifier under which _value_ is saved, unique in the database scope across the cluster. This string can be up to 512 bytes. |
| **value** | `T`      | The value to be saved for the specified _key_.                                                                                       |
| **index** | `long`   | <ul><li>`0` if creating a new key</li><li>The current version of _value_ when updating a value for an existing key.</li></ul>        |

**Returned object**:

<TabItem value="compare_exchange_result" label="compare_exchange_result">
```csharp
public class CompareExchangeResult<T>
{
    public bool Successful;
    public T Value;
    public long Index;
}
```
</TabItem>

| Return Value  | Type   | Description                                                                                                                                            |
|---------------|--------|--------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Successful**| `bool` | <ul><li>_True_ if the save operation has completed successfully</li><li>_False_ if the save operation failed</li></ul>                                 |
| **Value**     | `T`    | <ul><li>The value that was saved if the operation was successful</li><li>The currently existing value in the server upon failure</li></ul>             |
| **Index**     | `long` | <ul><li>The version number of the value that was saved upon success</li><li>The currently existing version number in the server upon failure</li></ul> |


<Admonition type="note" title="Note:" id="note" href="#note">

When calling the 'Put' operation, the index from the request is compared to the index that is currently stored in the server (compare stage).  
The value is updated only if the two are **equal** (exchange stage).
  
</Admonition>

## Create items via a cluster-wide session

* Compare-Exchange items can be created and managed on the advanced session (`Session.Advanced`)  
  Other options are listed in this [compare-exchange overview](../../../client-api/operations/compare-exchange/overview.mdx#how-to-create-and-manage-compare-exchange-items).

* When working with compare-exchange items from the session,  
  the session **must be opened as a [cluster-wide session](../../../client-api/session/cluster-transaction/overview.mdx#open-a-cluster-transaction)**.


<Admonition type="note" title="">

#### Example

<Tabs groupId='languageSyntax'>
<TabItem value="Sync" label="Sync">
```csharp
// The session must be first opened with cluster-wide mode
session.Advanced.ClusterTransaction.CreateCompareExchangeValue(
    key: "Best NoSQL Transactional Database",
    value: "RavenDB"
);

session.SaveChanges();
```
</TabItem>
<TabItem value="Async" label="Async">
```csharp
// The session must be first opened with cluster-wide mode
session.Advanced.ClusterTransaction.CreateCompareExchangeValue(
    key: "Best NoSQL Transactional Database",
    value: "RavenDB"
);

await session.SaveChangesAsync();
```
</TabItem>
</Tabs>

* `SaveChanges()` throws a `ConcurrencyException` if the key already exists.
* An `InvalidOperationException` exception is thrown if the session was Not opened as **cluster-wide**.

</Admonition>
