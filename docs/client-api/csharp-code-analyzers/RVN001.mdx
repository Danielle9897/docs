<Admonition type="note" title="">

* **RVN001** reports assignments to an index's `Map` or `Reduce` property inside a method instead of directly in the constructor.

* **Default severity**: `Info`  
  **Automated code fix**: No

* In this article:
   * [Description](#description)
   * [Trigger condition](#trigger-condition)
   * [How to resolve](#how-to-resolve)
      * [Before (triggers RVN001)](#before-triggers-rvn001)
      * [After (correct)](#after-correct)
   * [See also](#see-also)

</Admonition>

<Panel heading="Description">

The RavenDB client builds the index definition from the `Map` and `Reduce` expressions when the index is deployed.  
If these expressions are assigned in a separate method, that method may not run before the definition is built,  
for example if it is called conditionally or not at all.
    
If `Map` is still unset when the definition is built, the client throws `InvalidOperationException`.  
If `Reduce` is unset, the resulting definition is map-only.

</Panel>

<Panel heading="Trigger condition">

The analyzer reports any assignment to an index's `Map` or `Reduce` property inside a method of the index class rather than in a constructor.
It does not trace calls, so it also fires when the method is always called from the constructor,  
or when a method reassigns a `Map` the constructor already set. Abstract index classes are checked too.

This rule does not report assignments to local variables named `Map` or `Reduce`,  
or calls to `AddMap` or `AddMapForAll` inside methods.

</Panel>

<Panel heading="How to resolve">

Assign `Map` (and `Reduce`, for map-reduce indexes) directly in the constructor body.

---
    
### Before (triggers RVN001)

```csharp
public class OrdersByCompany : AbstractIndexCreationTask<Order>
{
    public void Configure()
    {
        // Triggers RVN001: assigned in a method, not in the constructor
        Map = orders => from o in orders 
                        select new { o.Company, o.Employee };
    }

    public OrdersByCompany()
    {
        Configure();
    }
}
```
<br/>
    
### After (correct)

```csharp
public class OrdersByCompany : AbstractIndexCreationTask<Order>
{
    public OrdersByCompany()
    {
        Map = orders => from o in orders
                        select new { o.Company, o.Employee };
    }
}
```

</Panel>
