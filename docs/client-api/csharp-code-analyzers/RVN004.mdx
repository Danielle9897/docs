<Admonition type="note" title="">

* **RVN004** reports a missing `Map` assignment in a RavenDB index class.

* **Default severity**: `Info`  
  **Automated code fix**: No

* In this article:
   * [Description](#description)
   * [Trigger condition](#trigger-condition)
   * [How to resolve](#how-to-resolve)
      * [Before (triggers RVN004)](#before-triggers-rvn004)
      * [After (correct)](#after-correct)
   * [See also](#see-also)

</Admonition>

<Panel heading="Description">

Indexes that derive from `AbstractIndexCreationTask<TDocument>` or `AbstractIndexCreationTask<TDocument, TReduceResult>`
and use the standard `CreateIndexDefinition()` implementation must assign `Map` before the client builds the index definition.
    
Without a `Map`, the client throws `InvalidOperationException` ("Map is required to generate an index…") when it builds the index definition,
so the index is never deployed.

</Panel>

<Panel heading="Trigger condition">

The analyzer fires when no `Map` assignment is reachable from any constructor of the index class or its base classes,  
including a base class from a referenced project.

An assignment found in one constructor or a method it calls is enough to suppress RVN004.  
The rule does not verify that every constructor or execution path assigns `Map`.

The following are not reported:

- Abstract index classes. Their subclasses are checked instead.
- Indexes that override `CreateIndexDefinition()`.
- Multi-map indexes. See [RVN005](./RVN005.mdx).
- JavaScript indexes (`AbstractJavaScriptIndexCreationTask`), which define their maps as strings.
- Generic index classes, and index classes that are private or protected or nested in a private or protected class.
- Indexes whose base classes cannot be analyzed, for example a base class from a compiled assembly without generated index metadata.

</Panel>

<Panel heading="How to resolve">

Add a constructor (or update the existing one) that assigns the `Map` property.

---
    
### Before (triggers RVN004)

```csharp
public class Orders_ByCompany : AbstractIndexCreationTask<Order>
{
    // No constructor — Map is never assigned; RVN004 fires on the class name
}
```
<br/>
        
### After (correct)

```csharp
public class Orders_ByCompany : AbstractIndexCreationTask<Order>
{
    public Orders_ByCompany()
    {
        Map = orders => from o in orders
                        select new { o.Company, o.Employee };
    }
}
```

</Panel>
