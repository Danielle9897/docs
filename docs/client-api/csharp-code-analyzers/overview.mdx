<Admonition type="note" title="">

* RavenDB ships a set of C# code analyzers embedded in the `RavenDB.Client` NuGet package.  
  They inspect client code at compile time, identifying common misuse patterns before the application runs.
    
* These **C# code analyzers** are distinct from the **text analyzers** used in index definitions for full-text search.  
  For tokenizers, stemmers, and language analyzers, see [Using Analyzers in Indexes](../../indexes/using-analyzers.mdx).    

* In this article:
   * [Distribution](#distribution)
   * [Severity](#severity)
   * [Code Fixes](#code-fixes)
   * [Rules](#rules)

</Admonition>

<Panel heading="Distribution">

The analyzer assembly (`Raven.Analyzers.dll`) and code-fix assembly (`Raven.Analyzers.CodeFixes.dll`) are included in `RavenDB.Client.nupkg` under `analyzers/dotnet/cs/`. 
No separate install is required.  
    
Once the client package is referenced, the analyzers run automatically on every build.  
Automated code fixes can be applied through a supported IDE or code-fix tool.

</Panel>

<Panel heading="Severity">

<Admonition type="info" title="">

#### New rules default to Info severity 
    
New rules default to `Info` severity in the client release that introduces them.  
Diagnostics reported at `Info` do not fail builds, even with `TreatWarningsAsErrors` enabled.

In a later client release, the rules listed in this article are automatically promoted to `Warning`,  
except RVN006, RVN007, and RVN008, which remain at `Info`.

If `TreatWarningsAsErrors` is enabled, diagnostics reported as `Warning` can fail the build.
Address or suppress relevant occurrences before upgrading to a client version where these rules default to `Warning`.

You can override the default severity of individual rules in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.RVN012.severity = warning
dotnet_diagnostic.RVN013.severity = error
```

</Admonition>

</Panel>

<Panel heading="Code Fixes">

<Admonition type="tip" title="">
    
#### Rules with automated code fixes    

Automated code fixes are suggested code changes that you can choose to apply.

- **[RVN011](./RVN011.mdx)**  
  Rewrites `store.OpenSession()` / `store.OpenAsyncSession()` to `batch.OpenSession()` / `batch.OpenAsyncSession()` inside a subscription `Run` lambda.
    
- **[RVN012](./RVN012.mdx)**  
  Rewrites independent eager `Load` / `Query` calls into lazy registrations and reads each result through `.Value` (awaited for async calls).
  Reading the first value sends all pending lazy operations in the same session to the server in a single request.

</Admonition>

</Panel>
